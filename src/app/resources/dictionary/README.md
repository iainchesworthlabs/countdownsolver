# Word lists

One list per language, `words_<code>.txt`, one word per line, embedded in the app as a resource.

| File | Words | Origin |
|---|---|---|
| `words_en.txt` | about 122,000 | Built by the maintainer from an internal spreadsheet of Countdown resources, which another of the maintainer's projects also uses. |
| `words_fr.txt`, `words_de.txt`, `words_es.txt`, `words_ar.txt`, `words_he.txt`, `words_yi.txt` | a few hundred each | Short lists the repository has carried since the languages were added, to give each language a working game. |

The English list is kept as it is. Before the app goes to outside testers or a store listing, the list's sources are to be
reviewed, and it is replaced with an openly licensed list if that review finds a problem.

A person can use their own list instead: see [Getting started](../../../../docs/getting-started.md#using-your-own-word-list).
